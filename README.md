# RedL1zar — personal links

Личная страница-визитка со ссылками на Steam, Pinterest, Spotify и Telegram.

В проекте также есть:

- текущий трек Spotify;
- текущая игра Steam;
- поиск треков в Яндекс Музыке;
- анонимные сообщения в Telegram;
- плейлисты, birthday-вкладка и секретная canvas-игра.

## Cloudflare

Standalone-версия для Cloudflare Worker находится в каталоге [`cloudflare/`](cloudflare/). В нём есть отдельный `README.md` с инструкциями по KV, секретам, Spotify OAuth, подключению домена и деплою.

Секреты в репозитории не хранятся.
